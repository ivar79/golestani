# پرامپت‌های مستقل هر فاز — Google AI Studio (Gemini) + Google Stitch
## سامانه معرفی و جست‌وجوی کسب‌وکارها — ۷ فاز، هرکدام خودکفا برای اجرا در Session جدا

---

## قبل از استفاده — نحوهٔ کار با Stitch + AI Studio در این پروژه

- **Google Stitch** فقط برای **طراحی/تولید اولیهٔ صفحات UI** (Layout، رنگ‌بندی، ساختار بصری) استفاده می‌شود — نه برای کد نهایی و نه برای منطق Backend.
- خروجی Stitch (HTML/CSS یا تصویر طرح) فقط **مرجع طراحی** است؛ Gemini در AI Studio باید آن را به Component واقعی Next.js + TypeScript + Tailwind، هماهنگ با ساختار پروژه، بازنویسی کند — نه Copy-Paste خام HTML.
- فازهای سنگین از نظر UI (۲، ۳، ۴، ۵، ۶) یک بخش «Stitch» دارند. فاز ۱ سبک (فقط صفحات ورود/ثبت‌نام) و فاز ۷ اصلاً نیازی به Stitch ندارد.
- چون هر فاز را در Session/Chat جدا در AI Studio اجرا می‌کنید، **هر پرامپت زیر کاملاً خودکفاست** و تمام قوانین لازم (Workspace، Approval Gate، امنیت، Git، گزارش‌دهی) را دوباره در خودش دارد — نیازی به ارجاع به پرامپت فاز قبل نیست، چون Gemini در هر Session حافظهٔ فازهای قبل را از روی Workspace واقعی (فایل‌ها، Git Tag، Decision Log) می‌خواند.
- ترتیب استفاده در هر فاز: (۱) اگر فاز UI دارد، ابتدا پرامپت Stitch را در stitch.withgoogle.com اجرا کنید و خروجی طراحی را ذخیره کنید → (۲) کل پرامپت فاز را در یک Session جدید AI Studio با Gemini 3.1 Pro Preview بدهید و به آن اشاره کنید که طرح Stitch در دسترس است (یا اسکرین‌شات/کد HTML آن را ضمیمه کنید).
