# لینک عمومی برای تست موبایل (تونل)

## لینک عمومی فعلی (Pinggy — بدون نیاز به نصب چیزی)

**سایت (فرانت‌اند Next.js):**
```
https://jlwai-194-110-207-146.free.pinggy.net
```

**توجه:** در اولین باز شدن، صفحه هشدار Pinggy نمایش داده می‌شود.
باید دکمه «Visit Site» (بازدید از سایت) را بزنید تا وارد سایت اصلی شوید.
این صفحه هشدار فقط یک‌بار ظاهر می‌شود.

## تونل در حال اجرا است
- تونل روی پورت **3000** (Next.js) فعال است.
- تونل **۶۰ دقیقه** اعتبار دارد (نسخه رایگان Pinggy).
- بعد از انقضا، کافی است دوباره اجرا کنید:
  ```
  ssh -o StrictHostKeyChecking=no -p 443 -R 80:localhost:3000 a.pinggy.io
  ```

## ⚠️ نکته مهم درباره API
چون فرانت‌اند از `.env.local` آدرس API را می‌خواند و این آدرس `http://192.168.1.102:8000/api` است،
**تونل فقط برای باز کردن خود سایت از اینترنت کار می‌کند، اما API از داخل سایت روی موبایل (در اینترنت) قابل دسترسی نیست** — API روی شبکه داخلی (Wi-Fi) کار می‌کند.

### دو راه‌حل:
1. **تست داخل Wi-Fi:** موبایل را به همان Wi-Fi وصل کنید و از آدرس `http://192.168.1.102:3000` استفاده کنید (API هم کار می‌کند).
2. **تست کامل از اینترنت:** باید یک تونل جداگانه هم برای API (پورت 8000) بسازید:
   ```
   ssh -o StrictHostKeyChecking=no -p 443 -R 80:localhost:8000 a.pinggy.io
   ```
   و بعد لینک تونل API را در `.env.local` به‌صورت `NEXT_PUBLIC_API_URL=https://<لینک تونل API>/api` تنظیم کنید و Next را دوباره اجرا کنید.

## ابزارهای دیگر (اگر Pinggy کار نکرد)

- **ngrok:** (فیلترشدگی دارد، احتمالاً کار نمی‌کند)

- سرور API (داکر): پورت 8000 (در حال اجرا)
- تونل Pinggy: فعال روی پورت 3000 (۶۰ دقیقه)
